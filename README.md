# Vývoj .NET aplikací s podporou GitHub Copilot

Školení zaměřené na představení GitHub Copilota a jeho integraci do .NET projektů pro efektivní vývoj aplikací s pomocí AI agentů. Účastníci se seznámí s možnostmi delegování vývojových úloh na GitHub Copilot agenty, naučí se je využívat v praxi, jak uhlídat kvalitu jejich práce, efektivně spravovat kontextové okno a jak s jejich pomocí akcelerovat dodávky softwarových řešení postavených na platformě .NET.

---

## Toto školení vám pomůže

- Porozumět možnostem GitHub Copilota v kontextu celého vývojového procesu.
- Efektivně delegovat vývojové úlohy na AI agenty.
- Nastavit a přizpůsobit Copilot agenty pro váš tým a projekt.
- Obecně zvýšit kvalitu vašich .NET aplikací.
- Navrhovat architektury .NET aplikací vhodné pro AI-first přístup.
- Zvýšit rychlost a kvalitu dodávek bez zvyšování kapacity týmu.

---

## Kdo by se měl kurzu zúčastnit?

- .NET vývojáři, kteří chtějí pracovat efektivněji při běžných pracovních úkonech.
- Architekti, kteří chtějí postavit architekturu vhodnou pro AI-first přístup.
- Senior vývojáři a Tech Leadi hledající způsoby akcelerace vývoje a revize změn.
- Týmy přecházející na AI-asistovaný způsob práce.

## Náplň kurzu

## Úvod do GitHub Copilota
- Co je GitHub Copilot a kde ho lze využít
- Přehled funkcí: chat, completion, code review, agenti

## GitHub Copilot CLI

- Instalace a konfigurace GitHub Copilot CLI
- Příkazy pro generování kódu, vysvětlení a refaktoring z terminálu
- Integrace CLI do skriptů a CI/CD pipeline
- Rozdíly oproti IDE integraci a kdy CLI preferovat

## IDE integrace

- Instalace a nastavení rozšíření ve VS Code a Visual Studiu
- Inline completion, chat panel a code review v editoru
- Kontextové okno – jak Copilot „vidí" váš kód a projekt
- Účtování na základě tokenů: co je token, jak se počítá kontextové okno a jak to ovlivňuje náklady
- Nová aplikace Agents

## Přizpůsobení Copilota

- Instrukce (Instructions) – globální a projektové řízení chování
- Prompts – tvorba zjevných šablon pro opakované úlohy
- Custom agenti – konfigurace agentů pro specifické role v týmu
- Skills – rozšíření schopností agentů vlastními dovednostmi
- Hooks – automatické akce při událostech ve vývoji
- MCP servery – napojení agentů na externí nástroje a datové zdroje
- Plugins – integrace třetích stran do pracovního postupu
- Copilot jako LLM provider – využití předplatného v externích AI nástrojích, např. Open Code

## Architektury vhodné pro AI-first vývoj

- Principy návrhu aplikací pro efektivní spolupráci s AI
- Modularita, čistá architektura a oddělení zodpovědností
- Vzory vhodné pro delegování na agenty

- Jak správně formulovat zadání pro agenta
- Zpracování výstupů a validace výsledků

## Testování a kvalita kódu

- Generování unit a integračních testů
- Statická analýza a refaktoring s pomocí agentů
- Kontinuální integrace a automatizované kontroly

## Prompt engineering pro vývojáře
