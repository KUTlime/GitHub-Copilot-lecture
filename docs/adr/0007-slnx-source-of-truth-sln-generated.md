# ADR 0007: AgentShop.slnx is the source of truth, AgentShop.sln is generated

- Status: Accepted
- Date: 2026-10-11

## Context

The repository must ship both the modern `.slnx` and the classic `.sln` format (older tools and IDEs). Two
hand-maintained solution files drift apart, and with two solution files in one folder every `dotnet` command
without an explicit solution fails with MSB1011.

## Decision

- `AgentShop.slnx` is edited (projects are added with `dotnet sln AgentShop.slnx add`).
- `AgentShop.sln` is generated by the file-based app `eng/sync-solutions.cs` using the official
  `Microsoft.VisualStudio.SolutionPersistence` library: `dotnet run eng/sync-solutions.cs`.
- `dotnet run eng/sync-solutions.cs -- --check` compares projects, solution folders and solution items and fails if
  they differ; it runs in `eng/verify.ps1` and therefore in CI.
- All documented commands pass `AgentShop.slnx` explicitly.

## Consequences

- No drift between the two formats; a forgotten regeneration fails the build pipeline with an actionable message.
- `AgentShop.sln` must never be edited by hand.
